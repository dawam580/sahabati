# سحّابتي — Sahabati

متجر شحن ألعاب واشتراكات وبطاقات رقمية بالدينار الليبي.

## التشغيل محلياً

```bash
npm install
npm run build:css      # بعد أي تعديل على كلاسات Tailwind في index.html أو admin.html أو js/
ADMIN_PIN='كلمة-سر-قوية' npm start
npm test
```

ثم افتح `http://localhost:5000`، ولوحة الإدارة على `/admin.html`.

## كيف يعمل

- **الخادم (`server.js` + `store.js`) هو مصدر الحقيقة:** يسعّر الطلب من الكتالوج المحفوظ على الخادم، ويتحقق من رقم الهاتف وكرت التعبئة ومعرّف اللاعب، ويحجز الأكواد الرقمية.
- **الأكواد تبقى مخفية:** لا يظهر الكود للعميل إلا بعد أن تؤكد الإدارة الدفع.
- **قاعدة البيانات الكاملة للمدير فقط:** `/api/database` يحتاج تسجيل دخول المدير. كلمة السر في متغير البيئة `ADMIN_PIN`، ولا تُرسل إلى المتصفح أبداً.
- **تعديلات الأسعار تصل للجميع:** ما يغيّره المدير من اللوحة يُحفظ على الخادم ويظهر لكل العملاء.
- **بدون خادم:** إذا فُتح الموقع على استضافة ثابتة (مثل GitHub Pages) يعمل المتجر محلياً في المتصفح، لكن بدون هذه الحماية.

## متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `ADMIN_PIN` | كلمة سر لوحة الإدارة. **إلزامي في الإنتاج.** إن لم يُضبط تُطبع كلمة سر مؤقتة في سجل الخادم عند كل تشغيل. |
| `DATA_DIR` | مجلد حفظ الطلبات والأكواد والكتالوج (افتراضياً `.data/`). يجب أن يكون على **قرص دائم**. |
| `TRUST_PROXY` | عدد البروكسيات أمام الخادم. ضعه `1` على Render أو Railway أو خلف Nginx حتى يعمل حد الطلبات لكل زائر. اتركه `0` إذا كان الخادم مكشوفاً مباشرة. |
| `PORT` | المنفذ (افتراضياً 5000). |

## النشر

يحتاج المتجر **خادم Node.js مع قرص دائم**، لأن الطلبات والأكواد تُحفظ في ملفات داخل `DATA_DIR`:

- **Railway أو Render:** أنشئ خدمة Web من هذا المستودع.
  - أمر التشغيل: `npm start`.
  - أضف قرصاً دائماً (Volume أو Disk) واضبط `DATA_DIR` على مساره.
  - اضبط `ADMIN_PIN` و`TRUST_PROXY=1`.
  - تنبيه: الخطط التي لا تتضمن قرصاً دائماً تمسح البيانات عند كل إعادة تشغيل.
- **VPS:** شغّل `npm start` عبر `pm2` أو `systemd` خلف Nginx مع HTTPS.

لا تستخدم `localtunnel` للإنتاج: الرابط مؤقت ويتوقف عند إغلاق الجهاز.

احتفظ بنسخة احتياطية من مجلد `DATA_DIR` بانتظام.
